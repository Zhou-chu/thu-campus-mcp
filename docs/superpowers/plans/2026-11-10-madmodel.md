# MadModel Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 提供自动登录和续期的本机 OpenAI 兼容模型服务。
**Architecture:** lib/madmodel 负责协议/配置、DPAPI 会话与版本锁、浏览器登录、自动检查和 HTTP 代理；CLI 与校园浏览器/MCP 入口接入这些模块。
**Tech Stack:** Node >=22 ESM、node:http、现有 playwright-core/proper-lockfile、Windows DPAPI。
**Spec:** docs/superpowers/specs/2026-11-10-madmodel-design.md

## Global Constraints
- 不读取或另存密码，不运行 install --unified --apply，不改写其他客户端配置。
- 模型目录来自现场前端；回环默认 127.0.0.1:8765；定时检查 300000 ms、刷新提前 900000 ms。
- 生成请求仅明确 401 且未输出时重试一次；注销不被在途任务覆盖。

## Review Focus
- 认证页面 HTML 200 不得作为模型成功结果。
- 下游断开时取消上游；流中断不重试。
- 账号切换、并发续登、注销竞态。
- 外网监听时强制下游 key，令牌不进入状态/日志。
- 浏览器占用、验证码、取消与超时必须有限退出。
