# 纸墨工作台改版验收

## 本轮范围

针对布局比例、层次不清、重复边框表单和操作反馈不足进行整批改版，不更换黑白纸墨方向，不引入外部字体或装饰依赖。

- 侧栏增加功能图标、反差选中态与按下反馈，设置入口固定在侧栏底部。
- 顶栏与主内容共享内层容器，纠正宽屏百分比padding导致的不对称留白。
- 设置页改为一张操作面板内的分区设置行：标题、控件、状态对齐；窄屏变为单列。
- 配对码与退出动作按内容定宽，不再铺满整屏。帮助、诊断、隐私范围仍主动展开。
- 输入区提供完整边界和聚焦反馈，操作控件统一高度；真实异步请求显示pending、防重复、成功反馈与持续就地错误，支持减弱动态效果。
- 模型保存失败回退原选择并保留可见错误。认证证据、私有云盘范围、写入审批、计算与同步状态语义未改动。
- 流事件分发由深层else-if展平为switch，不改流事件语义；流式与停止回归全部通过。
