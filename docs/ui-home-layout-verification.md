# 参考效果图：首页布局验收

## 本轮变更

以用户最新效果图为布局依据，不改变已完成的参考侧栏与灰阶材质：

- 空对话采用“校园工作台”眉标、衬线“今天，想完成什么？”、宽输入面板、五项校园操作的三段结构。
- 输入面板上层写消息，下层左侧添加内容与校园云盘，右侧真实模型选择、刷新与图标发送；停止操作仍可独立使用。
- 开始对话或打开非空历史后隐藏首页标题与快捷栏，消息独立滚动，输入与模型控件保持可达。没有为大标题挤压真实消息区。
- 未交作业、课程更新、私有云盘文件、雨课堂只填可编辑草稿，不自动发起模型请求；课程增量更新保留写入确认，不再绑定某台机器的本地目录。登录状态进入真实服务核验页。
- 加号提供真实工具、云盘、工作区设置入口，不放未实现的附件上传按钮。云盘芯片展开既有核验结果、私有范围和查询/设置入口，不写死已连接。
- 真实模型来自既有目录，不照抄效果图模型名。紧凑模型栏保留加载、保存、失败与恢复状态。切页返回仍保留未发送草稿；新对话明确清空草稿。
- 菜单支持Esc、点击外部关闭与键盘焦点；窄屏底栏分行，不缩成不可点击的小控件。

规范、组件目录与离线缓存同步更新；校园认证、云盘私有审计、工具执行及风险审批的服务端逻辑未改。

## 单元覆盖率

Node原生V8，范围为首页动作模块、侧栏模型及异步反馈三个模块，不是整个前端覆盖率。25项通过，无跳过，行100.00%、分支98.65%、函数100.00%；其中新首页模块三项均100.00%。

动作配置、顺序、未知/原型属性ID、冻结对象、只填草稿/页面导航、空首页与执行态边界均有测试。DOM集成由真实浏览器覆盖，不以纯数据单测冒充页面验证。

## 静态可维护性

项目自定义TypeScript AST指标，范围为主界面、首页模块、侧栏模型和异步反馈四个模块。175个函数，171个未越软阈、4个越软阈、0个硬超限，97.71分。

公式`round2(100 × 未越软阈函数 / 函数总数)`；软阈复杂度20/嵌套5/有效行100/参数5，硬上限50/8/200/8，至少90分且无硬超限。没有调整阈值；该指标不是Sonar或视觉评分。

深浅主题分别测试390、1280、1536、1920、2350、2560共12组：

- 标题、输入面板、常用操作保持三段顺序；无页面或主内容横向溢出。
- 首页大标题32–72px，发送目标52×52px；390×640空首页输入面板仍在可视区。
- 加号、云盘展开与Esc关闭、私有云盘草稿均实际操作。
- 原预览内拦截历史GET装入受控长消息与Markdown表格；有消息后首页标题隐藏，390×640消息区259.75px，输入面板底部549.75px，小于视图底部573.75px。
