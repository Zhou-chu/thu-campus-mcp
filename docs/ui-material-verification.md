# 扩散材质与参考侧栏验收

## 实现范围

按用户最新要求调整视觉规范：大面积深色使用扩散黑灰，浅色使用对应白灰，不再平铺死黑/死白。主要表面采用半透明填充、20–24px背景模糊、低对比斜向反光、内缘高光和微弱接触阴影；内容卡不层层追加背景采样。控件圆角12px、主要面板22px、内联字段6px，主题分段控件内层9px。

侧栏按用户参考图组织：建筑线形标识、品牌、描边新对话、四项主导航、最近三条真实会话、底部云盘状态与设置。宽屏304px、普通桌面272px，选中态为半透明灰底与左侧4px短竖线，不再整块反白。主导航字号20/22px，窄屏仍保留五项底部导航。

最近会话从既有会话API读取，不照抄参考图标题；新对话只清当前视图，不删除历史。打开历史使用真实读取，并防止迟到响应覆盖更新的导航意图。会话刷新失败保留旧列表并给出重试入口。云盘标签只消费经过既有认证/私有范围校验的presentation，缺完整范围的ready不能显示已连接。

认证、私有云盘范围、审批、模型与计算服务端逻辑未更改。新增静态模块已加入离线资产缓存，缓存版本递增。

## 实际浏览器

原有预览地址、真实Chromium、100%缩放；后台未重启。深浅主题分别验证390、1280、1536、1920、2350、2560共12组：

- 所有宽度无横向溢出，顶栏与设置主体左边线误差0px。
- computed背景实际包含两层radial-gradient及一层linear-gradient，不仅声明颜色变量。
- 面板实际圆角22px、控件12px，玻璃实际为blur(20px)及saturate(.85)。
- 浏览器模拟减少透明度后，实际backdrop-filter为none，回退为不透明表面；不支持模糊的回退CSS已提供，未冒充旧浏览器实机验证。
- 主操作高度52px；390×640消息区168px，输入可达；无页面脚本错误。
- 截图覆盖两种主题的304px左栏，以及390/1920/2350px完整设置页；仅保存在忽略的本地验收目录，不提交个人会话截图。
