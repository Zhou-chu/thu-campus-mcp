# BUG-003: [服务登录态] — 短间隔再次核验登录状态 — 网络学堂与图书馆从已登录变为未登录

**报告者：** 用户（生产 WebUI 实测）
**日期：** 2026-11-28
**严重程度：** High（P1）
**复现频率：** 已观察到一次，是否稳定复现待确认。

## 摘要

用户在连接与服务页看到全部服务已显示“已登录”后，短时间内再次点击“核验登录状态”，网络学堂及图书馆座位变为“未登录”。这与 #178 的 Agent/UI 跨入口不一致有关联，但本报告关注同一 UI 内连续核验导致的状态回退。

## 预期行为

在校园会话仍有效、身份没有变更的情况下，重复核验应保持“已登录”。如果确实失效，须以实际受保护接口响应为依据；如果是核验暂时不可用，应与未登录区分，并显示可执行的恢复动作。不得为保持绿色而掩盖真实失效。

## 实际行为

第二次核验后网络学堂、图书馆座位显示“未登录”，而清华云盘、荷塘雨课堂、MadModel模型、体育场馆仍显示“已登录”。用户确认前后时间间隔很短，具体秒数未记录。

## 复现步骤

前置：使用本人授权的清华账号，打开生产实例 WebUI，进入“连接与服务”页；账号及会话由本人完成认证。

1. 确认页面上所有服务均显示“已登录”。
2. 不主动退出、更换账号或清除会话，短间隔再次点击“核验登录状态”。
3. 等待本轮核验完成，比较两次状态。
4. 观察网络学堂和图书馆座位是否从“已登录”变为“未登录”。

最小复现：同一已登录设备、同一校园身份、两次相邻核验。未由审查会话再次访问真实校园验证；生产现象由用户报告和第二次核验后的截图提供。

用户在审查对话中提供第二次核验后的服务状态截图。网络学堂及图书馆座位为橙色“未登录”，其余可见四项为绿色“已登录”。未提供第一次核验截图；初始全部已登录由用户陈述。截图未作为附件上传，避免携带账号区域信息。

## 影响

- 服务状态可信度下降，可能导致重复登录及不必要的认证操作。
- 影响网络学堂、图书馆正常使用及后台恢复能力的判断；目前未知会话本身是否实际失效。
- 未知可靠临时解决方法。
